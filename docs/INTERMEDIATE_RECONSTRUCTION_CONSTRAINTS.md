# Komuheftic and Sisengwigwo reconstruction constraints

## Result

The current evidence supports **diachronic lineage constraints**, not complete
synchronic inventories for intermediate Komuheftic or Sisengwigwo. A required
segment in this register must have occurred somewhere in the branch history
because a documented rule consumes it or an attested historical form contains
it. The evidence does not establish that all required segments coexisted at a
single date.

The validated register is `config/intermediate_reconstruction.json`. It links
each segment claim to a rule in `config/family_history.json` or an attested
worked derivation in `data/historical_worked_examples.json`.

## Komuheftic lineage

The documented history directly requires these Proto-Losica consonants at
some point in the Komuheftic lineage:

```text
p t k kʼ b d g kʷ gʷ ts β n l r
```

The evidence presently requires vowels:

```text
i a o
```

The following Proto segments remain unconstrained by a documented Komuheftic
rule input or supplied Komuheft lexical derivation:

| Type | Unconstrained segments |
|---|---|
| Consonants | `m j w` |
| Vowels | `e u` |

Their absence from the required set is not a loss claim. Modern Komuheft has
some matching segments, but the modern inventory alone cannot distinguish
direct inheritance from later recreation or merger.

## Sisengwigwo lineage

The Tegofarela history and supplied forms require these Proto-Losica
consonants somewhere in the Sisengwigwo lineage:

```text
p t k kʼ g kʷ gʷ ts β r
```

The evidence presently requires vowels:

```text
i a
```

The unconstrained Proto segments are:

| Type | Unconstrained segments |
|---|---|
| Consonants | `b d m n l j w` |
| Vowels | `e o u` |

Again, this is a statement about the coverage of the supplied historical
evidence. It is not evidence that those segments disappeared immediately
after the c. 1036 split.

## Why no single intermediate inventory is given

The daughter descriptions provide relative ordering for several changes, but
they do not assign absolute dates to individual rules. Consequently, three
different objects must remain separate:

1. the provisional Proto-Losica inventory at the family split;
2. the set of segments required at various times in each later lineage;
3. the complete modern Komuheft and Tegofarela inventories.

Combining the second set into one phoneme chart would assert coexistence that
the sources do not demonstrate. For example, Komuheft inherited `*kʷ` changes
before `*gʷ` creates a new `/kʷ/`; placing every historical input and output in
one inventory would erase that chronology.

## Evidence needed for complete reconstruction

A defensible sequence of intermediate inventories requires:

- additional explicitly authored historical examples where the project later defines them;
- examples for the currently unconstrained Proto segments;
- morphological boundaries and stress for each historical input;
- clearer conditioning for the Tegofarela reflexes of `*gʷ`;
- relative-order relations connecting the currently separate rule clusters;
- dates or independently motivated periods for inventory snapshots.

Until that evidence is supplied, the validator requires both simultaneous
inventory status and absolute chronology status to remain `unresolved`.
