# Executable methodology

The authoritative method is implemented by:

- `losica_engine/causal_stream.py`
- `losica_engine/causal_attestation.py`
- `losica_engine/experiential_language.py`
- `losica_engine/causal_grammar.py`
- `losica_engine/causal_history.py`
- `losica_engine/causal_adapter.py`
- `losica_engine/causal_validation.py`
- `tests/test_causal_engine.py`

`CAUSAL_ARCHITECTURE.md` specifies their ordered inputs, transformations,
outputs, acceptance tests, and failure conditions. `verify.sh` executes the
release gate.
