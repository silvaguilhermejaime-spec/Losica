# Losica schemas

The release uses these machine-readable contracts:

- `losica-complete-language/2` for the v0.25 generated language state;
- `losica-typological-profile/2` for sampled grammar, reference, agreement, and numeral architecture;
- `losica-morphology/2` for generated inflection and derivation;
- `losica-history/2` for chronological stages;
- `losica-provenance-graph/1` for empirical and generated provenance.

The complete-language schema carries the generated profile, lexicon, paradigms, construction inventory, semantic schema, history, capability probes, and provenance graph in one validation target.
